# iPhone 系统设置读屏探针

此探针借鉴 [ZXTouch Rootless v1.0.1](https://github.com/Epic0001/zxtouchrootless/tree/v1.0.1) 的屏幕捕获方式。它作为单独的只读测试组件构建，包含 SpringBoard 插件和对应的注入过滤文件。源代码采用 GPL-3.0-only，见 COPYING。

只监听 `127.0.0.1:46030`。每次连接处理一条固定请求。只在竖屏且前台 App 是系统「设置」时捕获，原图只在手机内存中处理。OCR 结果限制为预设的中英文菜单名称。TCP 回环限制的是网络范围，同一台手机上的其他进程仍可能访问端口。

| 请求（以 CRLF 结尾） | 结果 |
| --- | --- |
| `00` | 探针是否运行 |
| `30` | 成功截取画面后的宽和高 |
| `27` | 识别到的预设设置菜单名称 |

成功响应采用 `0;;application/json;;字节数\r\n`，后接指定字节数的 UTF-8 JSON。其他命令直接断开。

云端手动工作流构建并验证 arm64/arm64e 插件签名，生成 rootless deb。安装前需要获得用户对越狱及系统插件安装的明确同意。真机验收先确认手机本机可连、电脑通过 Wi-Fi 无法连接，再打开系统设置验证截图尺寸和「通用」等文字。通过后单独设计触控测试。

同一次构建生成独立的「读屏测试」App。打开 App 检测本机探针，点「开始读屏测试」后有 7 秒可以切到系统「设置」，再切回查看结果。短时后台运行能否支持该流程需要在这台手机上验证。测试 App 没有模型接入，使用单独的数据目录。
